\section{Production Challenges Solved}
\begin{itemize}[leftmargin=.18in]
\itemx{\textbf{Double spending on redemption:} Concurrent redeem requests could pass the balance check together. Added a per-user Redis redeem lock and moved the wallet debit to commit before calling the payout provider, with a compensating credit on failure and idempotent payout retries, so a balance is never spent or paid twice.}
\itemx{\textbf{QR code scanned twice at the same moment:} Prevented double point credits by combining per-QR Redis locks with a row lock (SELECT FOR UPDATE) inside one database transaction.}
\itemx{\textbf{Slow downstream services:} Payment, SMS and KYC providers sometimes hung and held API requests open. Added timeouts, request cancellation and retries with backoff only for safe, idempotent calls, and moved slow work to background queues.}
\itemx{\textbf{Background jobs stuck or duplicated:} Investigated BullMQ stalled jobs and duplicate WhatsApp sends; tuned retries and backoff, made workers idempotent, and separated enqueue failures from worker failures using Bull Board and job state.}
\itemx{\textbf{API blocked by heavy file parsing:} Large purchase-sheet Excel uploads froze the Node.js event loop for all users; moved parsing to worker threads so APIs stayed responsive during uploads.}
\itemx{\textbf{Slow dashboard and report queries:} Used EXPLAIN ANALYZE to find full table scans, added composite indexes and removed duplicate indexes that slowed every write.}
\itemx{\textbf{Database connection pool saturation:} Traced request timeouts to long transactions holding pooled connections; shortened transactions and kept external HTTP calls outside them.}
\itemx{\textbf{Redis caching and cache stampede:} Added Redis caching for hot reads with clear invalidation rules, and protected expensive keys from many requests rebuilding them at once.}
\itemx{\textbf{Redis Cluster CROSSSLOT errors:} Traced multi-key failures to keys landing in different cluster slots; redesigned keys with hash tags so related keys share a slot.}
\itemx{\textbf{Safe migrations with zero downtime:} Ran schema changes as backward-compatible expand-and-contract steps; after a migration silently missed tables, added checks that compare source and target schemas instead of trusting the tool's status.}
\itemx{\textbf{Unreliable LLM output:} Made model responses safe for business logic using JSON-schema validation, truth checks, response caching, a circuit breaker and a deterministic fallback.}
\end{itemize}
